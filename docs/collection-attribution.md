# Practice collection provenance

Display names do not establish ownership or change reuse rights. Question metadata and selection were retrieved from the public references on 2026-10-07; no problem statements, solutions, videos, artwork, or creator biographies are bundled. Confirm appropriate permission before public redistribution of these referenced selections. Codolio's terms are at https://codolio.com/terms-and-conditions.

- **interview-launchpad** refers to Manasi Deshmane’s DSA Sheet (https://codolio.com/question-tracker/sheet/manasi-deshmane-dsa-sheet?category=all): 70 mappings, 66 unique questions.
- **dsa-deep-dive** refers to Arsh DSA Sheet (https://codolio.com/question-tracker/sheet/arsh-dsa-sheet?category=all): 287 mappings, 282 unique questions.

The references repeat some questions in several groups. PrepYard keeps the first occurrence so one canonical problem appears once per collection. Source articles remain outbound resources. One blank upstream title is repaired from its mapping title or URL. URL fragments and surrounding whitespace are removed. SPOJ identity uses the problem code. Checksums and removed duplicate mapping IDs are recorded in scripts/patterns/collection-provenance.json.

Interview Hotlist is a PrepYard ranking rule derived from approved published company observations; it does not copy another sheet. It uses only positive all-time percentages, deduplicates each company/question, and ranks the maximum reported percentage, company coverage, then title/URL. Percentages describe source reporting, not interview probability. It selects up to 20 per primary DSA topic and refreshes on every database read. No frequencies are fabricated for unreported topics.
